# Regulatory Analysis Skill

Reference documentation for identifying problematic regulatory patterns and evaluating regulations for modernization.

## Quick Reference

| Pattern | Key Signal | Example |
|---------|------------|---------|
| Prescriptive Formatting | Specific paper sizes, margins, ink colors | CA subdivision maps: 1-inch margins, 18x26" paper |
| Technology Monopoly | Mandates proprietary tech | Table saw AIM requirement (SawStop only) |
| Death by 1000 Cuts | Multiple fees, steps, agencies | SF restaurant: $22,648 + 61 steps |
| Regulatory Capture | Protects incumbents | Atlanta: food trucks banned within 200ft of restaurants |
| Exclusionary Rules | Debt/criminal history barriers | "Clean hands" rules blocking permits over small debts |

## Quick Evaluation Questions

1. Does the burden match the risk?
2. Could this be done electronically?
3. Does this create a monopoly?
4. Does this protect incumbents from competition?
5. Are there duplicative requirements across agencies?
